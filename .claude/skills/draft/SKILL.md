# Draft from the brain

1. Name the company. Read `brands/<company>.md`.
2. Run `bun run cli search <company> good` for ideas to use.
3. Run `bun run cli search <company> bad` for patterns to avoid.
4. Write the draft. Put the file path after every point, such as `[vault/ideas/learnwithparam-memory-is-files.md]`.
5. If the vault has no note for a point, leave the point out. Do not invent a source.
6. End with the bad notes you avoided and why.
